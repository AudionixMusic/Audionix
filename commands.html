Audionix Commands

/play <url or keywords>
Plays music from a YouTube URL or keyword search.
/playnext <url or keywords>
Plays the specified track next, bypassing the queue.
/search <query>
Search YouTube for a song and list top results.
/showqueue
Displays the current music queue.
/pause
Pauses the current track.
/unpause
Resumes the paused track.
/stop
Stops the music, clears the queue, and disconnects.
/loop
Toggles loop mode for continuous playback.
/volume <1-100>
Sets the playback volume.
/mute
Mutes the bot's audio.
/unmute
Unmutes the bot's audio.
/setchannel
Admins only: Restricts bot usage to this channel.
/clearchannel
Admins only: Removes channel restriction.
